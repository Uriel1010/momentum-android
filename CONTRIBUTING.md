# Help Momentum take its next step

Ideas, bug reports, documentation, translations and focused code changes are welcome.

## From an idea to an issue

Search existing issues first. Use the feature or bug template, describe the moment where you needed help, and explain the outcome you wanted. You can also prepare an issue from Settings → Suggestions for Momentum in the app. Review the browser draft and submit it yourself.

GitHub issues are public. Remove personal tasks, screenshots, backup contents, notification text and device identifiers before sharing. The app does not upload screenshots automatically.

## From an issue to a pull request

Discuss substantial changes in an issue first. Fork the repository, create a branch, make a focused change and open a pull request describing the problem and resulting behavior. Link the issue where relevant. Include relevant tests and, for visual changes, synthetic Hebrew/English light/dark screenshots.

Use the isolated QA package for fixtures. Never clear or replace data in a personal Momentum installation. Preserve Room and backup compatibility. Respect RTL/LTR, large text, reduced motion and Android permission decisions. Keep keys, tokens and personal device data out of the repository.

See the developer guide for build, signing and test instructions. An idea does not need a code contribution to be useful. This repository does not currently include a general source-code license grant; third-party components retain their own notices.
